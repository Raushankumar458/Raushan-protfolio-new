# Raushan Kumar — Immersive Portfolio

A cinematic React + TypeScript portfolio using Three.js (`@react-three/fiber`) and Framer Motion. The two supplied sketch-city videos are used directly in the Hero and Journey sections.

## Sections
- Hero / immersive city scene
- About
- Journey / supplied sketch-city video
- **Projects** (kept as a standalone section)
- Contact
